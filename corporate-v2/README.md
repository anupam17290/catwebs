# CatWebs Corporate v2 — Prototype

An isolated, static-first corporate homepage prototype for CatWebs 2.0.

## Preview locally

From the repository root, run a static server, for example:

```bash
python -m http.server 8000
```

Then open:

`http://localhost:8000/corporate-v2/`

No package installation or build step is required.

## Important

This is a review prototype, not a production replacement. Existing corporate pages remain unchanged. Internal links point back to the existing root-level pages so the prototype can be reviewed without breaking current routes.

Before promoting this page to `/`, update canonical metadata, link paths, navigation, sitemap and deployment configuration, then complete regression testing.
