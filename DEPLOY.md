# CatWebs — Brand Rebuild Deployment

This package is a clean rebuild of the public CatWebs website based on the CatWebs visiting card/catalogue direction and the current repository structure.

## Replace

Upload/replace the root website files and folders from this package in the GitHub Pages repository.

Important files:
- `css/style.css`
- `js/script.js`
- `index.html`
- `local.html`

The existing clinic and coaching demos are retained.

## Asset rule

The main CatWebs website now uses WebP assets from:

`assets/images/webp/`

The large original PNG website imagery has been removed from the deployment package because no public page references it anymore. The demo-specific PNG assets inside `clinic-demo/` and `coaching-demo/` are retained.
